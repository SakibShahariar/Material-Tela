# Material-Tela

Material-recolored icon theme: Tela folders + monochrome app icons, tinted from your wallpaper accent (generated by [Matugen](https://github.com/InioX/matugen)).

The `mm`/`folder_icon.sh` workflow recolors this theme automatically on every wallpaper change; the accent color is embedded in each SVG, so a single pass swaps teal -> pink -> blue and any other color.

## Install

```
./install.sh
```

or manually:

```
mkdir -p ~/.icons
cp -r Material-Tela ~/.icons/
gsettings set org.gnome.desktop.interface icon-theme Material-Tela
```

## Fonts / Sizes

Scalable SVG icons (`apps/scalable`), folder icons in 16/22/24/scalable, standard Tela layout.
